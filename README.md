# About this project 

## Motivations 

This is a simple self-learning project with the goal of helping me revise my foundational programming knowledge. 

## What the project is:

This project aims to be a standalone collection of core data structures implemented, tested, and documented in the Python programming language. 

Its purpose is to demonstrate my understanding of these concepts and that I can build these structures correctly. 

## Setting out goals 

#1. Build structures and algorithms without the help of AI tools to build problem-solving muscle (sit in discomfort of being stuck and overcome it without AI use).

#2. Revise foundational programming concepts to be more confident in tests and interviews during the job recruitment process.

#3. Have an active, well-established GitHub repo with a consistent commit history. Use feature branching and merge via pull requests (PRs) to mirror real team workflow just to keep the habit.

## Roadmap 

- start simple with stacks, queues, dequeues
- work way up to recursion and linked lists concepts.  


## Direction Intentions

- to explore building a simple search engine after having revised foundations.
